# Case study template

A single-page tool for writing marketing case studies. No build step, no dependencies.

## Put it online with GitHub Pages (free)

1. Create a free account at github.com.
2. Click **New repository**. Name it `case-study`. Keep it **Public**. Create it.
3. Click **uploading an existing file**, drag in `index.html`, and click **Commit changes**.
4. Go to **Settings > Pages**. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
5. Wait 1-2 minutes. Your site is live at `https://YOUR-USERNAME.github.io/case-study/`.

## Using it

- Answers save in your browser on that device and are not sent anywhere.
- **Download as file** saves a .txt of your case study.
- **Print or save as PDF** gives a clean page to save as PDF.
- Use a separate browser tab or the Clear button to start a new case study. Download the first one before clearing.
